# 阈值-指标分析

## 方法学

阈值在**验证集**上选择（最大化不参与F1），测试集仅评估一次，避免数据泄漏。

## 单次运行结果（seed 42）

验证集最优阈值：**0.46**

测试集评估（阈值=0.46）：

| 指标 | 数值 |
|------|------|
| 准确率 | 73.81% |
| 不参与F1 | 0.4976 |
| 不参与召回率 | 61.29% |
| 不参与精确率 | 41.88% |
| 参与F1 | 0.8229 |

## 三种子稳定性

| 种子 | 验证集最优阈值 | 测试集不参与F1 | 测试集召回率 |

## 应用建议

模型对阈值高度敏感，且不同训练种子下最优阈值差异大。在实际部署前，需在目标场景的验证数据上重新校准阈值。
