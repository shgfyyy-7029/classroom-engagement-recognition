# 手表传感器融合实验

## 目的

验证DIPSER的智能手表传感器数据（心率、加速度计、陀螺仪、光线）能否补充视觉特征，提升课堂参与度识别性能。

## 数据

- 手表传感器：心率（1Hz）、线性加速度（100Hz）、陀螺仪（100Hz）、光线（5Hz）
- 每个JSON文件对应1秒，提取14维特征：心率均值(1) + 加速度均值(3) + 加速度标准差(3) + 陀螺仪均值(3) + 陀螺仪标准差(3) + 光线均值(1)
- 按“时:分:秒”与视觉序列对齐

## 实验一：剔除低匹配率subject

剔除手表匹配率<50%的subject后训练。

- 训练集不参与占比从20%降至9.1%
- 被剔除的69个subject集中在experiment_05、08、09（系统性缺失）

| 指标 | 纯视觉 | 融合（剔除版） |
|------|--------|---------------|
| 准确率 | 77.21% | 88.92% |
| 不参与F1 | **0.4979** | 0.1619 |
| AUC | **0.7630** | 0.5425 |

**问题**：数据分布发生偏移（不参与占比从20%降至9%），无法公平对比。

## 实验二：0填充，不剔除subject

保留全部subject，手表数据缺失时用全0填充。数据分布与纯视觉完全一致。

| 指标 | 纯视觉 | 融合（0填充版） |
|------|--------|----------------|
| 准确率 | 77.21% | 86.19% |
| 不参与F1 | **0.4979** | 0.2737 |
| 不参与召回率 | 53.52% | 31.11% |
| 不参与精确率 | 46.76% | 26.94% |
| AUC | **0.7630** | 0.7354 |

## 诊断过程

1. **时间对齐检查**：视觉与手表的秒键匹配率99%以上，对齐正确
2. **特征有效性检查**：手表特征数值正常（心率76-83，加速度/陀螺仪有波动，非全0）
3. **数据分布检查**：0填充版保持了与纯视觉一致的标签分布

## 结论

在排除了时间对齐、特征提取、数据分布偏移等技术原因后，融合模型的不参与F1（0.2737）仍显著低于纯视觉模型（0.4979）。

**手表传感器数据（心率、加速度、陀螺仪）对课堂参与度识别没有增量价值，简单拼接融合会引入噪声、干扰视觉特征的学习。** 课堂参与度的有效信号主要存在于视觉行为层面。

## 可能的原因

1. 课堂场景下学生坐着不动，心率和运动信号变化极小
2. 生理信号与“是否在听讲”的关联远弱于视觉行为（头部姿态、面部表情）
3. 手表特征的信息密度低，在GRU训练中被视觉特征淹没
