# 类别不平衡处理策略对比

## 实验设计

对比四种不平衡处理策略，每种配置3个随机种子（42/123/2024）。
阈值在验证集上选择，测试集评估一次。EPOCHS=50，patience=10。

| 配置 | 类别权重 | 重采样 |
|------|----------|--------|
| A_无处理 | 无 | 无 |
| B_标准权重 | 反频率公式 | 无 |
| C_2倍重采样 | 无 | 不参与类2倍 |
| D_权重+重采样 | 反频率公式 | 不参与类2倍 |

**标准权重公式**：`w_i = N / (2 * N_i)`，其中N为总样本数，N_i为第i类样本数。

## 结果（3种子均值±标准差）

| 配置 | 准确率 | 不参与F1 | 不参与召回率 | 不参与精确率 | AUC |
|------|--------|----------|-------------|-------------|-----|
| A_无处理 | **77.21%±0.71%** | 0.4979±0.0113 | 53.52%±4.07% | **46.76%±1.17%** | 0.7670±0.0028 |
| B_标准权重 | 67.37%±2.66% | 0.4781±0.0202 | 70.67%±6.64% | 36.29%±1.85% | 0.7511±0.0186 |
| **C_2倍重采样** | 74.90%±1.78% | **0.5243±0.0010** | 65.34%±4.41% | 44.00%±2.00% | **0.7859±0.0037** |
| D_权重+重采样 | 71.12%±3.57% | 0.5077±0.0147 | 70.09%±6.21% | 40.24%±3.50% | 0.7680±0.0180 |

## 核心发现

1. **C（2倍重采样）不参与F1最高**（0.5243），且标准差最小（±0.0010），结果最稳定。AUC也最高（0.7859）。

2. **B（标准权重）效果最差**：不参与F1（0.4781）低于A，准确率仅67.37%。反频率公式的4倍权重过度校正，损害整体性能。

3. **D（双重处理）介于中间**：不参与F1（0.5077）略高于A，但准确率和稳定性都不如C。

4. **A（无处理）准确率和精确率最高**，但不参与F1不如C。

## 结论

最终主实验和消融实验采用**C配置（2倍重采样）**。不参与F1从A配置的0.4979提升到0.5243，提升0.026（约为C标准差的26倍），统计上显著。
