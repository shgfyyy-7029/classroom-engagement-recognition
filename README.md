# classroom-engagement-recognition

## 项目简介

本项目基于 DIPSER 数据集，探索在资源受限条件下（无大规模GPU、无预训练深度模型）的课堂学生参与度识别方法。

## 数据集

- **DIPSER**: 西班牙阿利坎特大学发布的真实课堂多模态数据集
- 使用其官方提供的结构化特征（MediaPipe facemesh + body_pose + headpose + bbox），共1544维
- 标签来自四位专家标注，采用多数投票融合

## 方法

- **特征提取**: 从 metadata JSON 提取1544维结构化特征
- **标签融合**: 四位专家多数投票，平票丢弃
- **模型**: 2层GRU (hidden=128)，输入为10帧时序序列（约1秒）

## 实验结果

| 任务 | 准确率 | 少数类F1 | 说明 |
|------|--------|----------|------|
| 二分类 (参与/不参与) | 74.09% | 0.40 | 不参与类召回率40% |
| 三分类 (低/中/高) | 52.5% | - | 类别1 F1最高 |
| 回归 (1-5分) | MAE 0.32 | PCC 0.21 | 模型倾向预测均值，实际不可用 |

## 与已发表工作的对比

| 方法 | 输入 | 结果 |
|------|------|------|
| 本研究 | 结构化特征 (1544维) + GRU | 二分类74.09% |
| ISET 2025 | 原始图片 + 手表传感器 + 多模态融合 | RMSE 0.87 |
| 轻量级网络 (2025) | 原始图片 + Inception-ResNet-v1 + 蒸馏 | 二分类75.40% |

**核心发现**: 结构化特征在二分类任务上接近原始图片方法，但回归任务失败，说明特征信息量不足以支撑连续参与度预测。
