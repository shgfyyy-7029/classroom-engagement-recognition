# Classroom Engagement Recognition with DIPSER

## 项目简介

本项目基于DIPSER数据集，探索一种隐私友好、低部署成本的课堂学生参与度识别方法。系统比较了三种任务设定（二分类、三分类、回归）和七种特征组合，并对模型能力边界进行了严格评估。

## 数据集

本仓库**不包含数据集**。使用本项目需自行向DIPSER原作者申请数据集。

- **DIPSER**: 西班牙阿利坎特大学发布的真实课堂多模态数据集
- **数据申请地址**: https://www.scidb.cn/en/detail?dataSetId=7856c716c0cc4589a23ee4a23d8a0893
- **官方GitHub仓库**: https://github.com/luis-marquez/DIPSER-A-Dataset-for-In-Person-Student-Emotion-and-Engagement-Recognition-in-the-Wild
- 本项目使用官方结构化特征（MediaPipe facemesh + body_pose + headpose + bbox），共1544维
- 标签来自四位专家标注，经多数投票融合

## 方法

- **特征提取**: 从metadata JSON提取1544维结构化特征
- **模型**: 2层GRU (hidden=128)，输入为10帧时序序列
- **数据划分**: 按Subject划分（同一学生不跨集合），按Group分层（7:1.5:1.5）
  - 训练集: 38个subject, 97784个序列
  - 验证集: 8个subject, 21159个序列
  - 测试集: 11个subject, 30412个序列
- **方法学**: 阈值在验证集上选择，测试集仅评估一次

## 主要实验结果

### 二分类（参与/不参与，全特征1544维）

**注意：测试集参与类占约79%，全猜"参与"的trivial baseline准确率约79%。**

模型主要价值在不参与类识别能力：

| 指标 | 数值 | 说明 |
|------|------|------|
| **不参与F1** | **0.5243 ± 0.0010** | 核心指标 |
| 不参与召回率 | 65.34% ± 4.41% | |
| 不参与精确率 | 44.00% ± 2.00% | |
| 准确率 | 74.90% ± 1.78% | 参考价值有限 |

训练配置：2倍重采样（不参与类样本被抽到的概率是参与类的2倍）。

### 三分类（低/中/高）

- 准确率: 52.5%（早期探索性实验，未经最终验证流程修正）

### 回归（预测1-5分）

- PCC: 0.21，模型倾向预测均值，实际不可用

## 消融实验

7种特征组合（3种子，验证集选阈值，2倍重采样）。完整结果见 `ablation/results/ablation_results.md`。

| 组合 | 维度 | 准确率 | 不参与F1 | 不参与召回率 |
|------|------|--------|----------|-------------|
| **full** | 1544 | 74.90% | **0.5243** | 65.34% |
| headpose_body | 102 | 68.26% | 0.4989 | **74.72%** |
| facemesh_body | 1533 | 71.38% | 0.4765 | 62.00% |
| body_pose_only | 99 | 64.44% | 0.4757 | 76.10% |
| facemesh_head | 1437 | 69.34% | 0.4599 | 61.76% |
| facemesh_only | 1434 | 68.44% | 0.4518 | 61.48% |
| headpose_only | 3 | 75.49% | 0.4473 | 48.86% |

**主要发现**：

1. **full配置综合最优**：不参与F1最高（0.5243），标准差最小（±0.0010），结果最稳定。
2. **headpose_body不参与召回率最高**（74.72%），适合"宁可多抓"的场景。
3. **headpose_only在重采样下不稳定**：标准差±0.0659，是7个配置中最大的。

## 类别不平衡处理

对比了四种策略（完整结果见 `results/imbalance_comparison.md`）：

| 配置 | 准确率 | 不参与F1 | AUC |
|------|--------|----------|-----|
| A_无处理 | 77.21% | 0.4979 | 0.7670 |
| B_标准权重 | 67.37% | 0.4781 | 0.7511 |
| **C_2倍重采样** | 74.90% | **0.5243** | **0.7859** |
| D_权重+重采样 | 71.12% | 0.5077 | 0.7680 |

**结论**：C（2倍重采样）不参与F1最高（0.5243），且最稳定（±0.0010）。B（标准权重）过度校正，效果最差。最终主实验采用C配置。

## 窗口长度对比

测试了5帧、10帧、20帧三种时序窗口（完整结果见 `results/window_comparison.md`）：

| 窗口 | 准确率 | 不参与F1 |
|------|--------|----------|
| 5帧 | 73.69% | 0.4847 |
| **10帧** | **77.21%** | **0.4979** |
| 20帧 | 79.36% | 0.4252 |

在当前标签融合和序列构建条件下，10帧窗口取得了最优的不参与F1和最好的稳定性。20帧虽然准确率最高，但不参与召回率仅40.13%，倾向于预测多数类。

*注：窗口长度实验在A配置（无重采样）下完成，与主实验的C配置不同。*

## PCA分析

1544维特征中前5个主成分解释96.38%方差，但PCA降维后性能显著下降（PCA-10不参与F1 0.3703，全特征0.4979）。说明方差最大的方向主要反映面部共性结构，而非参与度判别信息。无监督降维不适用于此任务。详见 `results/pca_analysis.md`。

## 特征选择分析

对比了无监督降维（PCA）和有监督特征选择（互信息）。PCA降维后性能显著下降（PCA-10不参与F1 0.3703），而互信息选择的MI-50用50维达到全特征97%的性能（不参与F1 0.4786 vs 0.4979）。说明参与度信息存在于低方差维度中，需要用有监督方法才能找到。详见 `results/feature_selection.md`。

## 手表传感器融合

尝试将DIPSER的智能手表数据（心率、加速度计、陀螺仪）与视觉特征融合。在排除时间对齐、特征提取、数据分布偏移等技术因素后，融合模型的不参与F1（0.27）仍显著低于纯视觉模型（0.50）。结论：手表传感器数据对课堂参与度识别无增量价值，简单拼接融合会干扰视觉特征的学习。详见 `results/watch_fusion.md`。

## 基线模型对比

为验证GRU的必要性，对比了多个基线模型（完整结果见 `results/baseline_comparison.md`）：

| 模型 | 准确率 | 不参与F1 |
|------|--------|----------|
| 多数类（全猜参与） | 78.83% | 0.0000 |
| LR | 69.75% | 0.3728 |
| MLP | 66.34% | 0.4084 |
| 帧级GRU（单帧） | 73.81% | 0.4632 |
| 序列GRU（10帧） | 77.21% | 0.4979 |

**结论**：GRU的时序建模带来稳定增益（比帧级GRU高0.035 F1）。但所有模型的准确率都低于多数类基线（78.83%），说明准确率在此任务上不可靠，应以不参与F1为主要指标。

*注：基线对比在A配置（无重采样）下完成，与主实验的C配置不同。*

## 模型评估

### 全特征二分类模型（C配置：2倍重采样）

| 指标 | 数值 | 随机基线 |
|------|------|----------|
| 准确率 | 74.90% ± 1.78% | — |
| 不参与F1 | 0.5243 ± 0.0010 | — |
| 不参与召回率 | 65.34% ± 4.41% | — |
| 不参与精确率 | 44.00% ± 2.00% | — |

模型对参与类的排序能力较强，但对不参与类的识别能力有限。不参与精确率约44%，意味着每判2.3个"不参与"，只有1个是真的。

## 与已发表工作的对比

| 方法 | 输入 | 使用原始图像 | 多模态 | 结果 | 算力需求 |
|------|------|-------------|--------|------|----------|
| 本研究 | 结构化特征(1544维)+GRU | 否 | 否 | 二分类不参与F1 0.5243 | 笔记本GPU |
| 轻量级网络(2025) | 原始图片+Inception-ResNet | 是 | 否 | 二分类准确率75.40% | 两张V100 |
| ISET(2025) | 原始图片+手表传感器 | 是 | 是 | 回归RMSE 0.87 | 大规模GPU |

**注意**：上述结果**不构成直接可比基准**。现有文献报告的是整体准确率，未报告少数类F1指标；本任务因类别不平衡（参与类占约79%），整体准确率参考价值有限，核心指标应为不参与F1和PR-AUC。本研究可在笔记本GPU上完成训练，算力成本显著更低。

## 项目局限性

1. **不参与精确率约44%**：每抓出2个走神学生，会冤枉约1.5个专心学生。模型只适合辅助教师初筛，**不适合自动判定学生走神**。
2. **测试集仅11个subject**：序列间存在重叠，指标的实际方差大于报告值。
3. **特征未经标准化**：缺失值用0填充的策略未经验证。
4. **标签噪声**：DIPSER标注者一致性约0.6，模型不参与F1 0.52可能已接近标注上限。
5. **实验配置不完全统一**：消融、窗口长度、基线对比在A配置下完成，主实验和最终消融采用C配置。不同实验间的对比需注意配置差异。
