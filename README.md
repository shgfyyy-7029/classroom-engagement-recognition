# Classroom Engagement Recognition with DIPSER

## 项目简介

本项目基于DIPSER数据集，探索**资源受限条件下**（无大规模GPU、无预训练深度模型）的课堂学生参与度识别方法。核心贡献是系统性比较了不同特征组合和任务粒度对识别效果的影响，并发现头部姿态是不参与识别的最强信号。

## 数据集

- **DIPSER**: 西班牙阿利坎特大学发布的真实课堂多模态数据集
- 使用其官方提供的结构化特征（MediaPipe facemesh + body_pose + headpose + bbox），共1544维
- 标签来自四位专家标注，采用多数投票融合（回归任务使用均值）

## 方法

- **特征提取**: 从metadata JSON提取1544维结构化特征
- **模型**: 2层GRU (hidden=128)，输入为10帧时序序列
- **任务**: 二分类、三分类、回归

## 数据集划分

- **划分原则**：按Subject划分，保证同一学生的所有数据只出现在一个集合中，避免数据泄漏
- **Group分层**：在三个Group内分别按7:1.5:1.5比例划分，保证每个集合中不同班级学生的比例一致
- **训练集**：38个subject，97784个序列
- **验证集**：8个subject，21159个序列
- **测试集**：11个subject，30412个序列
- **标签分布**：三个集合的标签分布与总体一致（标签0约20%，标签1约58%，标签2约22%）

## 主要实验结果

### 二分类 (参与/不参与)

| 特征组合 | 维度 | 准确率 | 不参与F1 | 参与F1 |
|----------|------|--------|----------|--------|
| facemesh+headpose | 1437 | **74.54%** | 0.4184 | **0.8369** |
| 全特征 | 1544 | 72.38% | 0.3847 | 0.8219 |
| **仅头部姿态** | **3** | 72.61% | **0.5139** | 0.8093 |

### 三分类 (低/中/高)

- 准确率: 52.5%
- 标签0召回率: 34.07%, 标签1召回率: 60.22%, 标签2召回率: 49.26%

### 回归 (预测1-5分)

- MAE: 0.32, RMSE: 0.40
- PCC: 0.21（模型倾向预测均值，实际不可用）

## 消融实验核心发现

对1544维结构化特征按来源拆分为7种组合，每种组合3个随机种子，阈值在验证集上选择。完整结果见 [ablation_results.md](ablation/results/ablation_results.md)。

**主要发现**：

1. **特征选择取决于应用目标**：纯头部姿态（3维）在整体准确率（75.5%）和参与识别上最优；头部+身体组合（102维）在不参与召回率上最优（82.1%）。

2. **纯头部姿态模型偏保守**：准确率高但不参与召回率仅43.9%，漏报较多。适合"不冤枉学生"的场景。

3. **身体姿态显著提升不参与召回能力**：加入body_pose后，不参与召回率从43.9%升至82.1%，代价是准确率从75.5%降至63.4%。

4. **面部网格对参与度识别贡献有限**：GRU容量对照实验（128/256/512）显示不参与F1无显著提升，说明瓶颈在特征信噪比而非模型容量。

5. **模型稳定性不足**：headpose_only的三种子最优阈值差异大，不参与召回率标准差达12.45%。
   
## 模型评估

### headpose_only模型的评估指标

| 指标 | 数值 |
|------|------|
| 准确率 | 72.61% |
| 不参与F1 | 0.5169 |
| 不参与召回率 | 70.3% |
| 不参与精确率 | 40.9% |
| AUC | 0.7721 |
| PR-AUC | 0.9304 |

### 阈值选择

最优决策阈值约0.46，此时不参与F1最高。不同阈值适用于不同应用场景，详见 [阈值分析](results/threshold_analysis.md)。

### 局限性

1. **误报率偏高**：不参与类精确率仅40.9%，模型目前只适合辅助教师初筛，不适合自动判定或自动警告
2. **特征信息量限制**：三分类和回归任务均未取得可用结果，说明结构化特征不适合精细参与度预测
3. **AUC与F1的差距**：模型排序能力尚可(AUC 0.77)，但决策边界模糊，两个类别的概率分布存在显著重叠

## 与已发表工作的对比

| 方法 | 输入 | 任务 | 数据范围 | 结果 | 说明 |
|------|------|------|----------|------|------|
| 本研究 | 结构化特征(1544维) + GRU | 二分类 | 全部9场景 | 准确率74.09% | 数据不平衡(不参与占20%) |
| 轻量级网络 2025 | 原始图片 + Inception-ResNet-v1 | 二分类 | 仅experiment_03 | 准确率75.40% | 类别接近平衡 |
| ISET 2025 | 原始图片 + 手表传感器 | 回归 | 全部场景 | RMSE 0.87 | 多模态融合 |

**注意**：三者的数据范围、任务类型和数据分布不同，上述数字**不构成直接可比基准**。这里仅列出供参考，说明在资源受限条件下结构化特征能达到大致相当的准确率水平，但在少数类识别和多任务能力上仍有明显差距。

**结论**: 在相同任务上，结构化特征+轻量GRU与原始图片+预训练模型的准确率差距仅1.3个百分点，但算力成本低几个数量级。
