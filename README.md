# Classroom Engagement Recognition with DIPSER

## 项目简介

本项目基于DIPSER数据集，探索**资源受限条件下**（无大规模GPU、无预训练深度模型）的课堂学生参与度识别方法。核心贡献是系统性比较了不同特征组合和任务粒度对识别效果的影响，并发现头部姿态是不参与识别的最强信号。

## 数据集

- **DIPSER**: 西班牙阿利坎特大学发布的真实课堂多模态数据集
- 使用其官方提供的结构化特征（MediaPipe facemesh + body_pose + headpose + bbox），共1544维
- 标签来自四位专家标注，采用多数投票融合（回归任务使用均值）

## 方法

- **特征提取**: 从metadata JSON提取1544维结构化特征
- **模型**: 2层GRU (hidden=128)，输入为10帧时序序列
- **任务**: 二分类、三分类、回归

## 主要实验结果

### 二分类 (参与/不参与)

| 特征组合 | 维度 | 准确率 | 不参与F1 | 参与F1 |
|----------|------|--------|----------|--------|
| facemesh+headpose | 1437 | **74.54%** | 0.4184 | **0.8369** |
| 全特征 | 1544 | 72.38% | 0.3847 | 0.8219 |
| **仅头部姿态** | **3** | 72.61% | **0.5139** | 0.8093 |

### 三分类 (低/中/高)

- 准确率: 52.5%
- 标签0召回率: 34.07%, 标签1召回率: 60.22%, 标签2召回率: 49.26%

### 回归 (预测1-5分)

- MAE: 0.32, RMSE: 0.40
- PCC: 0.21（模型倾向预测均值，实际不可用）

## 消融实验核心发现

1. **头部姿态是不参与识别的最强信号**：仅3维pitch/yaw/roll，不参与F1 (0.514) 超过全特征 (0.385) 33%，且三个随机种子下结果稳定（标准差±0.0007）。
2. **面部网格在不参与识别上贡献弱于头部姿态**：1434维facemesh的不参与F1仅0.37，显著低于headpose的0.51。
3. **模型容量不是瓶颈**：将GRU隐藏层维度从128提升至256和512，facemesh的不参与F1分别为0.372、0.383、0.348，无显著提升。这表明面部关键点的局限源于特征本身信噪比低，而非模型容量不足。
4. **高维特征稀释关键信号**：从3维扩展到1544维，不参与F1从0.51降至0.38，与参与度无关的结构信息干扰了关键信号的学习。
5. **参与类F1区分度有限**：所有组合的参与F1均在0.81-0.84之间，由于参与类样本占80%，该指标无法作为特征选择的依据。

## 与已发表工作的对比

| 方法 | 输入 | 结果 | 算力需求 |
|------|------|------|----------|
| 本研究 | 结构化特征(1544维) + GRU | 二分类74.09% | 笔记本GPU |
| ISET 2025 | 原始图片 + 手表传感器 + 多模态融合 | RMSE 0.87 | 大规模GPU |
| 轻量级网络 2025 | 原始图片 + Inception-ResNet-v1 + 蒸馏 | 二分类75.40% | 两张V100 |

**结论**: 在相同任务上，结构化特征+轻量GRU与原始图片+预训练模型的准确率差距仅1.3个百分点，但算力成本低几个数量级。

## 环境

- Python 3.9+
- PyTorch 2.x
- 单张笔记本GPU (CUDA)
