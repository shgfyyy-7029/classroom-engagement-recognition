# 项目总结：结构化特征在课堂参与度识别中的能力边界

## 研究问题

在资源受限条件下（无GPU集群、无预训练大模型），使用DIPSER官方提供的结构化特征进行课堂参与度识别，能达到什么水平？瓶颈在哪里？

## 实验设计

三种任务（二分类、三分类、回归）+ 五组分析（特征消融、窗口长度、类别不平衡、降维、基线对比）

## 核心发现

### 发现1：结构化特征能支撑二分类，不能支撑精细任务

| 任务 | 结果 |
|------|------|
| 二分类（参与/不参与） | 准确率77.21%，不参与F1 0.4979 |
| 三分类（低/中/高） | 准确率52.5% |
| 回归（1-5分） | PCC 0.21，模型预测均值，不可用 |

### 发现2：不参与识别是根本瓶颈

- 不参与类PR-AUC仅0.41，参与类PR-AUC 0.92
- 不参与类精确率约47%，每抓出2个走神学生，会冤枉2个专心学生
- 根源不是数据不平衡（欠采样实验证明），而是不参与行为本身异质（发呆、玩手机、聊天各不相同）

### 发现3：1544维中存在严重冗余，但降维需有监督

- PCA：前5个主成分解释96.38%方差，但降维后性能大幅下降
- 互信息选择：50维达到全特征97%性能
- 结论：方差大的方向不等于任务相关方向，需要标签引导才能找到有效维度

### 发现4：头部姿态是信息密度最高的信号

- 3维headpose的AUC（0.7721）略高于1544维全特征（0.7630）
- 但headpose_only的不参与召回率低（44%），加body_pose后升至82%
- 结论：头部姿态是干净但保守的信号，身体姿态补充了召回能力

### 发现5：时序建模有真实增益

- 序列GRU（10帧）不参与F1 0.4979
- 帧级GRU（单帧）不参与F1 0.4632
- 线性模型LR仅0.3728，MLP仅0.4084
- 结论：时序信息贡献了稳定增益（+0.035 F1），但不是决定性的

### 发现6：准确率在不平衡数据上不可靠

- 多数类基线（全猜参与）准确率78.83%
- 所有模型的准确率都低于这个基线
- 结论：应以不参与F1和PR-AUC作为主要评估指标

## 与已发表工作的对比

| 方法 | 输入 | 结果 | 算力 |
|------|------|------|------|
| 本研究 | 结构化特征(1544维) + GRU | 二分类77.21% | 笔记本GPU |
| 轻量级网络2025 | 原始图片 + Inception-ResNet | 二分类75.40% | 两张V100 |
| ISET 2025 | 原始图片 + 手表传感器 | 回归RMSE 0.87 | 大规模GPU |

**结论**：结构化特征在准确率上与原始图片方法接近（77.21% vs 75.40%），但代价是不参与识别能力弱（F1 0.50，精确率47%）。两者的差距揭示了特征信息量的重要性。

## 项目局限性

1. 不参与类精确率仅47%，模型只适合辅助初筛，不适合自动判定
2. 测试集仅11个subject，序列间存在重叠，指标方差被低估
3. 特征未经标准化，缺失值用0填充的策略未经验证
4. DIPSER标注者一致性约0.6，模型不参与F1 0.50已接近标注上限
